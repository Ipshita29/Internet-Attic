# Internet Attic

A little home for everything you find. Save links, sort them into illustrated rooms, tag and annotate them, and rediscover forgotten treasures.

React + Vite, plain CSS, React Router, Context API, localStorage. No backend: each visitor's attic lives privately in their own browser.

```
npm install
npm run dev
```

## Deploy to Netlify

Push the repo to GitHub, then in Netlify choose "Add new site", "Import an existing project" and pick the repo. `netlify.toml` already sets the build command (`npm run build`), publish directory (`dist`) and the SPA redirect.
